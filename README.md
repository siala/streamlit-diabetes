This is a simple illustration of streamlit (https://streamlit.io/) using the UCI Diabetes 130-US Hospitals for Years 1999-2008 dataset https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008.

The app is available online at [tutorial-diabetes-us.streamlit.app](https://tutorial-diabetes-us.streamlit.app/)

The source code is on GitHub at https://github.com/siala/tutorial-diabetes-us

The source code is designed to be simple and self contained. It was successfully tested with python 3.13.

To run the code locally, you need to install the python packages in requirements.txt and the softwares in packages.txt.

The main entry file is main_diabetes.py.
